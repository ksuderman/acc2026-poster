Galaxy on AnVIL

Galaxy makes sophisticated data analysis accessible to researchers without programming expertise. As the only no-code analysis solution on AnVIL, Galaxy brings hundreds of powerful tools and curated workflows to the cloud, all driven through an intuitive web interface. Researchers can build, run, reproduce, and share analyses while working securely with AnVIL-hosted data.

Advantages

  • Your own Galaxy: a private, customizable instance
  • No queue wait times: scalable AnVIL cloud resources
  • Connected to your data: from AnVIL, cloud, or local
  • No coding required: explore, run, and build via the web
  • Built on the Galaxy ecosystem: tools, workflows, tutorials all apply
  • Reproducible and shareable: rerun and share with collaborators

Elastic by Default

Small jobs run on the VM. Big ones get their own hardware, then release it.

  • No idle cluster
  • Up to 60 vCPUs and 240GB memory per job
